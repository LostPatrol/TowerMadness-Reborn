## 关键根因（已修）

1. **2D 菜单不可见的根因**：`menu+0x110/+0x114` 是 `MENU_setResolution` 的 **float 逻辑画布**（MENU_alloc 默认 320x480）。
   之前用整数 480/800 写入，被 `glOrthof` 当作 denormal float 读 → 投影塌缩，2D 全部不可见（3D 世界用独立投影仍可见）。
   现写入 float 位模式 `0x43F00000/0x44480000`（480/800），逻辑坐标=窗口像素。
2. **tab 命中**：常量在 libverde rodata，Ghidra 地址 0x372e80.. → ELF VA 0x362e80..（Ghidra=ELF+0x10000；曾误减 0x100000 导致 NaN/INT_MIN 点击）。
