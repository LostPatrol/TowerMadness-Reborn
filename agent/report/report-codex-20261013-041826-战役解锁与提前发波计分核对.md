# 战役解锁与提前发波计分核对

完成保留SO的定向静态核对，更新`docs/MODES.md`，未改动主代理的Game或菜单代码。

确认`unlockedHard()`读取持久化布尔标记，默认false。唯一setter调用来自`MENU_endGame`的DividedAttention胜利分支。原无限四个入口检查该标记，所以应在完成Medium战役后开放；不是完成MuttonsFolly后。完整链：PlainPlane胜利解锁Medium；DividedAttention胜利解锁Hard；MuttonsFolly胜利解锁Insane；Madness胜利设置通关标记。胜利要求游戏结束且羊数非零。

计分确认：最终分为rawScore+bonus+40*lives。首次发波奖励0；运行中单人提前发波存储20-trunc(elapsedMs/1000)。计数在dispatch建立：普通count，spawn非零count*3。最后一次递减必须来自击杀才计入单人bonus，不增加金币；最后一只漏怪无奖励。子怪不重复领取击杀gold。父分裂怪漏掉时计数只减1而不生成子怪，因此原计数可能无法归零，不能以场上清空替代该逻辑。

发现并交接Sandbox集成问题：原Sandbox配置使用Endless_Hard资源但10000起始金币，SHA-1种子必须hash该10000配置；用普通Hard的100金币配置计算seedOffset会改变无限敌人序列。已告知主代理使用Endless_Sandbox调用配置和种子helper。
