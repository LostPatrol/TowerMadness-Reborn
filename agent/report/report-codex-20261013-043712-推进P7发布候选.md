## 未完成的验收指标

1. Android原作画面／时序／数值动态对照：没有真机，按用户要求暂跳过；Android Studio不能在禁止模拟器的条件下替代真机，因此未请求无必要安装。
2. 原作精确动画、俯仰插值、阴影、skybox、粒子／炮口、羊被抓走收尾，以及移动版完整UI未恢复。过渡覆盖层使用很小Z偏移替代原关闭深度测试，透明排序按实例。
3. 战斗MT算法恢复，但桌面初始种子1及完整随机消费顺序未与原会话逐项对齐。完整活动链／多诱饵堵路检查、同刻排序仍有边界差异。桌面持续2／4倍速是便利性变化。
4. 112附加图原访问条件不复现，也不进入购买验证／广告范围；旧Android存档、联网／排行／多人不在交付范围。
5. 116地图尚未逐一完整自然通关；长时高压无限局及其已发波历史缓存、跨机器／Windows10、高DPI跨显示器、真实音频听感和循环接缝尚未实测。

本轮因此交付“原生功能发布候选”，保留总体计划的验收门槛；不能报告P5–P7完整原作等价验收全部完成。MEMORY已整理为当前真实基线与上述关键未解决项，README只保留功能、运行和开发说明。
