# P8 原战斗特效与外围流程集成简报

执行代理：codex。基于main/8cbbd29推进P8.3/P8.4及P8.5；Windows原生交付，模拟器仅用于开发对照。本轮未改Windows可选功能、未重启系统、未安装或运行原APK。

## 已实现

- 按原ARM静态函数、调用指令及资产恢复beam2激光、railspiral轨道炮、双层闪电/减速atlas、等级色、plasma四帧、炮口火光、火焰、弹坑、普通爆炸及四层核爆。地雷III核爆保留地雷弹坑参数，plasma命中移除错误的通用爆炸；flak复用原已消费第三个战斗随机高度，不改伤害或战斗RNG消费。
- Beam/Effect记录真实塔类型、出生时间和发射姿态；渲染器支持非均匀缩放、UV动画、原材质RGBA替换及point-size换算，视觉hash与战斗RNG分离。逐类截图发现火焰黑块及状态环白块，直接修正additive及环绘制后重新运行并审图。
- 关卡选择显示真实地图离屏预览、科技、波数、初始资金/羊数、最佳成绩；浏览保留当前局和镜头，明确开始后才切换。保存卡显示真实状态，胜利显示新解锁、支持下一战役，重复胜利不重复报告新解锁。
- 菜单退出及窗口关闭共用保存路径。真实保存失败时显示提示并保留当前游戏，第二次明确退出才允许放弃未保存进度；手动保存成功清除失败状态。

外围流程子任务由frontend_flow实现，静态视觉规格由native_effects恢复；主代理完成渲染接口、战斗事件、效果组装、主循环集成、直接修复及运行验收。修改入口见docs/FRONTEND.md、COMBAT_VISUALS.md、DEVELOPMENT.md和RENDERING.md。

## 尚未达到的指标

P8总体及“类似原作Windows适配版”的最终品质验收未完成。原作尚未成功进入游戏菜单；API24 Play x86此前仅到Android主屏，adb认证仍未闭合，不能将用户已允许调试等同于APK运行成功，也不能据此断言APK与Android Studio不兼容。

原realtime与暂停/倍速效果、lrand48/drand48序列、point-size屏幕字段及透明排序尚未动态对齐；导弹多层命中/原trail、flak初始blast、核爆2D条件、炮塔平滑和特殊动作、羊被抓完整收尾仍未全部恢复。状态/血条辅助与部分阴影保留桌面近似。密集及长时无限局、高DPI跨显示器、其他Windows机器、实际音频听感、116关全部自然通关未覆盖。

MEMORY已维护为当前实现、修改入口及剩余风险；TODO与agent/task未改。继续按P8计划闭合剩余效果/动作和原作对照，再扩大品质与发布验收，保持既有核心规则结果。
