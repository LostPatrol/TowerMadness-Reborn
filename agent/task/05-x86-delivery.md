# Task 05：横屏适配、个人离线版收尾与交付

## 最终目标

完成适合普通 Windows 显示器、可供用户完整游玩验收的 Windows 10/11 原生版本。优先适配 16:9、16:10 横屏及可缩放窗口，消除原竖屏画布导致的大面积两侧黑边，允许合理重排 GUI；尽量复用原 x86 核心、资源及界面风格，不依赖模拟器或开发环境。

优先交付 ZIP portable，也可采用 MSI；解压或安装后，双击 `TowerMadness.exe` 直接进入原菜单，无需参数、命令行、PowerShell 或 CMD 启动器，普通启动不显示控制台。横屏适配在正式发布前完成，最终回归和打包安排在其后。

## 行动计划

1. **横屏技术原型**：优先利用原 GAME/MENU/CAMERA 分辨率与宽高比接口，实现真实横屏投影，验证绘制、选塔、拖动、缩放共用正确坐标。先确认原代码已有能力与固定布局限制，再确定详细实现。
2. **GUI 与镜头适配**：战斗场景使用实际横屏视口；金币、生命、分数放顶栏，菜单、倍速、发波放边角，波次预览利用底部空间。轮盘跟随选中位置并避免越界，合理重排主菜单、选关、设置、教程及结算页面，同时调整点击区域。根据纵向地图调整默认取景与缩放，不改变地图、路径或玩法。
3. **直接启动与整理交付目录**：自动按 EXE 所在目录定位运行资源，整理 EXE、资源、存档、日志及简短说明；常用设置通过菜单、窗口或快捷键操作并适当保存，启动错误以可读界面提示。保留用户旧包和存档，提供清楚的存档接续方式。
4. **全面开放付费内容**：复核全部付费地图、炮塔和功能，移除购买、收据及联网验证要求；保留正常金币消耗、科技条件和通关解锁。
5. **补齐高价炮塔验收**：通过正常游戏收益准备资金，实际验证 Fusion Cannon、Railgun VI、Tesla 末级、Flamethrower III 的升级、攻击或特殊效果、出售及存读档。
6. **内容检查、回归与打包**：检查地图载入、资源引用、科技树、敌人及波次；完成横屏、核心功能和代表性战斗自动化验证。验证干净副本双击 EXE 启动、中文及空格路径、离线运行、存档接续；交付便携包或安装包、简短使用说明、已知问题及手动验收清单。

## 横屏验收重点

- 至少覆盖 1280×720、1920×1080（16:9）、1920×1200（16:10），以及动态缩放、最大化和常见 DPI 缩放；窄窗口下保持基本可操作。
- 3D 场景按实际宽高比绘制，模型比例正常；不以整体拉伸、裁掉必要内容或装饰填充冒充横屏适配。检查纵向地图的取景与地图外背景，保留方便的缩放和拖动。
- GUI 无关键遮挡或越界，文字和按钮可读，绘制位置与鼠标命中一致；覆盖窗口边缘建塔/升级、轮盘、教程指引及菜单切换。
- 更新依赖旧竖屏坐标的自动化操作，验证横屏下建升售、暂停、F5/F9、重启继续及调整窗口后的恢复。
- 以本机代表性真实战斗检查 60 FPS 目标及 120/不限帧切换，确认模拟速度不变；如实记录性能限制，不以隐藏菜单吞吐代表战斗表现。

横屏部分初估累计工作量：技术原型 2–4 小时、可玩版本 8–16 小时、完整发布候选 16–32 小时。此为开发验证预算参考，非硬性时限；原型后按固定布局的实际数量更新估算。

- 先读根目录 `AGENTS.md`、`MEMORY.md` 和 `docs/X86_CORE_REUSE.md`，以当前 x86 基线接续，不重启旧重建路线。
- 不要求逐关模拟完整通关；自动化覆盖必要功能和代表性战斗，完整游玩由用户手动验收。分别记录开发/自动化完成与用户验收完成。
- 不实现联网验证、在线排行等服务；Wiki、Guide、Credits 等普通链接可保留，访问失败不应阻断离线游戏。
- 首关资金不足升级卡顿移出必做项，不再专门扩大排查；后续若未再复现，则不作为缺陷或交付阻碍。
- 不修改原 APK/ELF 文件，不用改金币、生命、战斗速度或伪造结果完成验收；尽量直接修复问题对象，遵守最小改动原则。
- 优先保证本机可完整运行，不扩展为大型生产系统；不要求必须同时交付 MSI 和 ZIP。
- 保留用户数据及原始资源，测试使用隔离副本；保持当前低系统音量，常规验收默认静音。
- 如实列出无法完成或需用户协助的事项，不阻塞其他独立工作；交付附执行简报并维护 `MEMORY.md`。
