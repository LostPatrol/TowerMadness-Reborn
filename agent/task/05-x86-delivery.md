# Task 05：个人离线版收尾与交付

## 最终目标

完成可供用户完整游玩验收的 Windows 10/11 原生版本，尽量复用原 x86 核心、资源及界面，不依赖模拟器或开发环境。优先交付 ZIP portable，也可采用 MSI；解压或安装后，双击 `TowerMadness.exe` 直接进入原菜单，无需参数、命令行、PowerShell 或 CMD 启动器，普通启动不显示控制台。

## 行动计划

1. **直接启动与整理交付目录**：自动按 EXE 所在目录定位运行资源，整理 EXE、资源、存档、日志及简短说明；常用设置通过菜单、窗口或快捷键操作并适当保存，启动错误以可读界面提示。保留用户旧包和存档，提供清楚的存档接续方式。
2. **全面开放付费内容**：复核全部付费地图、炮塔和功能，移除购买、收据及联网验证要求；保留正常金币消耗、科技条件和通关解锁。
3. **补齐高价炮塔验收**：通过正常游戏收益准备资金，实际验证 Fusion Cannon、Railgun VI、Tesla 末级、Flamethrower III 的升级、攻击或特殊效果、出售及存读档。
4. **检查内容与桌面体验**：检查地图载入、资源引用、科技树、敌人及波次；针对性验证高分辨率和窗口缩放、60/120/不限帧、输入、暂停及存档。缺失内容按实际影响处理并如实记录。
5. **回归与打包**：完成必要自动化测试，验证干净副本双击 EXE 启动、中文及空格路径、离线运行、存档接续；交付便携包或安装包、简短使用说明、已知问题及手动验收清单。

## 范围与验收

- 先读根目录 `AGENTS.md`、`MEMORY.md` 和 `docs/X86_CORE_REUSE.md`，以当前 x86 基线接续，不重启旧重建路线。
- 不要求逐关模拟完整通关；自动化覆盖必要功能和代表性战斗，完整游玩由用户手动验收。分别记录开发/自动化完成与用户验收完成。
- 不实现联网验证、在线排行等服务；Wiki、Guide、Credits 等普通链接可保留，访问失败不应阻断离线游戏。
- 首关资金不足升级卡顿移出必做项，不再专门扩大排查；后续若未再复现，则不作为缺陷或交付阻碍。
- 不修改原 APK/ELF 文件，不用改金币、生命、战斗速度或伪造结果完成验收；尽量直接修复问题对象，遵守最小改动原则。
- 优先保证本机可完整运行，不扩展为大型生产系统；不要求必须同时交付 MSI 和 ZIP。
- 保留用户数据及原始资源，测试使用隔离副本；保持当前低系统音量，常规验收默认静音。
- 如实列出无法完成或需用户协助的事项，不阻塞其他独立工作；交付附执行简报并维护 `MEMORY.md`。
