# 桌面外围流程

`src/main.cpp` 的 `Desktop` 保存菜单选项、独立关卡预览和本次胜利的新解锁。`desktopScene` 绘制菜单、HUD与结算；`desktopInput` 统一按钮和快捷键；`desktopEvent` 隔离镜头输入。

点击关卡只建立独立的 `Game` 预览，不替换当前局。预览读取实际科技、初始资金、羊数和波次，地图图片由 `Renderer::mapPreview` 对原地图地形、树林及场景模型离屏绘制并缓存；只有“开始所选关卡”调用原模式加载。修改预览布局在 `desktopScene` 菜单分支，修改缩略图在渲染器接口。

`modeAvailable` 共用既有战役门槛和开始按钮判断。四战役顺序解锁，四个无限/沙盒入口都在完成分兵防守后开放；附加关卡沿用桌面资源库入口。科技及升级可用性仍取原配置，不从预览覆盖战斗规则。

`desktopCompletion` 由主循环记录真实胜利成绩，同时保留本次新获得的关卡/科技入口；`nextCampaign` 指定下一战役。重复胜利不再次报告新解锁。结算的下一战役按钮启动原模式的新防御局。

`savedSummary` 直接描述 `Profile` 中保存的关卡、波次及准备/战斗/暂停/胜负状态。继续调用原完整 `restoreState`，恢复成功后才替换当前局。保存失败显示中文提示；声音默认仍为零。菜单退出和窗口关闭共用 `requestExit`：保存失败后保留当前局，第二次明确退出才允许丢弃未保存进度；手动保存成功会清除失败状态。

本机集成构建的 `--desktop-test` 已通过浏览不弃局、预览不改镜头、明确开始、保存暂停与波次、战役门槛、三窗口布局及退出保存失败检查；`--input-test` 在原资金自然胜利重放后通过成绩记录、下一战役和重复胜利反馈。这些结果不构成原作动态保真或人类可用性最终验收。
